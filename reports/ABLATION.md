# 设计消融与修复核验 · v1.1

本报告区分已执行的确定性/浏览器检查与未来用户研究，不把原型测试当成市场或模型效果。

## 已执行的结构与交互对照

| 因素 | 对照 | 本轮观察 | 决定 |
|---|---|---|---|
| 首页粒度 | 同一天的14段经历平铺 / 7个外层场景块 | 原型保留同样16段跨日数据；上午3件、下午6件通过内部事件线访问。自动校验不漏、不重复归块，边界不越界 | 默认分块，关于页保留平铺对照 |
| 人物排列 | 固定 / 当前时段优先 | 自动检查确认活跃人物优先、同级稳定、并集110分钟而非重复117分钟；浏览器捕捉到换位中间位置，反向切换可恢复 | 默认动态，可固定一人和关闭换位 |
| 关系呈现 | 静态坐标式示意 / Cytoscape画布 | 当前真实节点拖动、画布平移、缩放、过滤、展开、引用返回均有检查；完整可见图受范围过滤 | 保留真正图交互与列表替代 |
| 证据密度 | 常驻长证据 / 小引用按需打开 | 来源不会挤满主页面；从引用返回恢复选中节点和视角 | 小引用、侧页、无来源不伪造 |
| 人物解释 | 单一断言 / 多候选与支持程度 | 可选择、否定和编辑回复；“已决定获奖”保留依据不足，不能进入事实 | 以当次沟通候选支持用户判断 |
| 日历范围 | 全自动个人排程 / 明确事项行动桥 | 测试检查确认、有效授权、冲突、撤销、版本与重复执行；ICS真实下载 | 只实现小而完整的安排链 |
| 界面说明 | 每页解释产品理念 / 直接动作与状态 | 主页面保留标题、内容、来源和操作；说明集中到帮助和交付资料 | 删除手写口号与无用长文 |

## 这次没有用来证明的事情

场景块首层入口变少并不等于用户效率提高；动态换位具有中间帧也不等于所有用户都会喜欢；图谱能展开不等于检索比列表更快。以上仍需在同数据、同任务下测查找时间、误解、误触和偏好。

## 后续用户对照（尚未执行）

1. 分块／平铺：找到“上午答疑后确认的算法口径”，观察定位与上下文恢复。
2. 动态／固定人物：在一天人数较多时找到指定时间的交谈者；允许搜索、固定与减少动态效果。
3. 图／列表：从评审反馈找后来改动与对应原句；两边拥有相同来源与范围。
4. 候选／无候选：理解一句反馈、提出回复，记录用户是否发现其他解释，避免将模型候选当成事实。
5. 手机／录音豆：在同一App比较手机占用、开始记录、标记与取回负担。没有实机数据前不宣称录音豆必胜。

## 测试明确保留的边界

自然语言理解用预置样例；动态图和时长采用确定性计算；声纹身份与情绪/心理测量没有执行；有限自动日历只操作本机演示数据。原型可以暴露并修复交互错误，不能消除未来真实算法、同步和服务接入的不确定性。
