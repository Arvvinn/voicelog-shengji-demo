## 交付内容

按已定稿的 Astra 融合规格在隔离副本内完成 A—F 范围。入口是本地离线单 HTML，CSS、原生 JavaScript、示例数据及 Cytoscape 均打包在页面中。继续从 `src/` 修改并运行 `python -X utf8 src/build_demo.py` 可重新生成入口；本轮没有直接手改生成 HTML。

保留原型的数据结构、分块时间线、时间区间并集计算、稳定人物身份、候选选择、来源定位和返回、日历状态机以及离线关系图。融合了认可方案的中文层级、青柠与森林绿、人物交汇、交流理解、日历分组样式。时间线仍是首页主体；示例人物、头像显示、实际引文时间和跨日安排按规格校正。

在用户连续反馈后，2026-09-27 又从源码调整了人物交汇和导航。最终人物页参照 v1.1 原版恢复全天纵向滚动：头像固定在图表顶部，图表内上下滑动浏览 08:30—21:00；可见约 120 分钟的时间段，时段菜单和上下箭头用于快速跳转。时间卡片依旧按真实分钟比例绘制，跨原窗口边界的交流保留完整时长。先前的横向定位线、右侧触点和底部滑块均已移除。滑动时人物动态排序仍可用，按住期间锁定排序，松开或取消后恢复。

底部导航改为离开屏幕边缘的独立圆角透镜。`src/glass.js` 在本机生成 SVG 位移图，用边缘折射、薄色层和高光模拟网页中的 Liquid Glass；“我的 → 外观与玻璃”可调节强度、实时预览，并保存到融合版专用本地存储键。实现参考 Apple 的 [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 和 [Get to know the new design system](https://developer.apple.com/videos/play/wwdc2025/356/)，以及 MIT 许可的 [Zettersten liquid-glass skill](https://github.com/Zettersten/skills/tree/main/skills/liquid-glass) 中的位移图思路；位移图代码由本项目实现。该效果是网页近似，不是 Apple 原生材质。正文卡片继续保持不透明，并在减少透明度、提高对比度等系统设置下退回实色。交互和数据仍由原有 DOM、JavaScript 与离线模型驱动，没有把玻璃效果做成整页图片。

随后按最新反馈，日历安排卡片去掉了左侧装饰圆点及细线；场景卡片图标在各自的方块内居中；“我的”页把录音豆放在第一项，外观设置移到靠后位置。跨页面切换时内容立即回到顶部，解决从长场景列表进入“我的”时个人资料被页头截住的问题。关联记忆在现有离线 Cytoscape 图上增加按连接距离衰减的跟随运动：拖动任一节点时，相连节点及周围节点同步移动，松手后缓慢稳定；减少动态效果时立即跟随。节点身份、颜色、引用与筛选逻辑不变。

收到“关系图太拥挤”的截图后，调整了完整图的 CoSE 布局距离与斥力，并取消额外压缩；总览优先显示主要标签，事情和原话的标签在悬停、点选或邻域聚焦时出现。最新修改把图谱弹层放回手机容器：从手机内容或桌面左侧入口点击，图谱始终在 390 CSS px 手机画幅内显示，不再覆盖电脑全屏。首次打开以可阅读的局部缩放进入，仍可拖动、双指缩放或点“查看全图”；来源定位与筛选继续可用。

根据最新反馈，桌面左侧改为十五个可点击的演示入口，按“时间线 → 人物交汇 → 交流理解 → 原话来源 → 日历”排出演示主线，再直达场景、关联记忆、有据对话、录音豆、玻璃外观、一天复盘、区间计算、心情、夜间声音和隐私。每项写明可体验的功能；录音豆图片缩小为辅助信息。侧栏可独立滚动，入口调用现有真实页面和状态，不建立空白展示页。

修复关联图“人物”筛选丢失连接的错误：筛选保留实际参与的事情节点和原有 participant 边，不再显示无关且孤立的项目／要点节点。“要点”筛选也保留其实际来源事情和 derived、used_in 等已有关系。筛选内的连接记录显示标签，关系线增强对比；图谱数据没有新增推断出的边。浏览器读取的人物视图为 9 个人物、11 条事情、15 条真实参与关系；只在显式打开“原话”后附加对应来源节点。

演示写入独立的 `voicelog-ui-merge-v1` 本地存储键；不会迁移或覆盖 `voicelog-v11`。浏览器拒绝本地存储时仍可临时操作，并明确提示本次修改不会持久化。

## 关键流程验收

- **人物与原话：** 时间线事件 → 对应人物交汇 → 人物页“交流理解” → 具体原话 → 完整记录中高亮被引用句 → 返回时恢复人物页、标签、日期、时间窗和焦点时间。
- **候选与草稿：** 人物解释可明确选择或拒绝；回复保存在草稿中，不会冒充已发送消息；选择与草稿经真实浏览器刷新后仍保留。
- **实际时间几何：** 人物轨道按分钟映射全天高度，短接触保持比例；跨越旧时窗边界的交流作为连续完整区间显示。图表独立纵向滚动，时间和人物排序随滚动更新；触摸中排序锁定，取消指针后解除。
- **底部遮挡与玻璃：** 首页滚到最底部时，“今天，留给明天”完整位于浮动导航上方。导航与手机左右及底部均有留白。玻璃强度实时改变 SVG 折射尺度，刷新浏览器后仍保留，且不碰旧键。
- **场景、日历与关联图：** 场景图标实际位于方块中心；日历卡片没有多余的左侧圆点和轨道；拖动完整关系图中的节点时，多数周围节点随之位移，且松手后布局保持有效。
- **关系图手机画幅：** 图谱弹层实际挂在手机容器中；桌面点击后其四边仍在手机边界内，初始缩放至少 58%，未自动调暗节点。手机内可点选、拖动、缩放、筛选、查看来源和返回。
- **桌面演示直达与筛选：** 左侧十五项可点击，人物交汇、交流理解、来源面板、日历、录音豆、复盘与隐私均从左侧实测直达；人物／要点筛选均保留真实连接节点和边，桌面人物筛选实拍显示 15 条参与关系。
- **日历：** 草稿 → 确认面板 → 显式确认后“本机已存” → 已存筛选 → ICS 下载。跨日任务冲突、取消、来源变更导致的过期草稿均被拦截。ICS 检查了事件标题和稳定 UID。
- **旧数据隔离：** 浏览器内预置旧键哨兵值后启动、选择候选、保存日历，旧键一直不变；初始状态不迁移旧键内容。
